# Operator Animation Guide

## What to Visualize
State glyph, operator sigil, and resulting state transition per frame.

## Timing and Frame Rate
Use 24/30 fps with one beat per operator invocation and interpolation between checkpoints.

## Visual Metaphors
Flame (transform), lattice (preserve), knot (bind).

## Data Flow from Engine Specs
Read operator traces from engine specs and map each trace event to a timeline keyframe.
