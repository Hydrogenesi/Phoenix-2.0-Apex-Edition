# Convergence Animation Guide

## What to Visualize
Trajectory bundles converging from branch clouds to a single apex attractor.

## Timing and Frame Rate
Variable-speed easing: fast branch pruning, slow final lock.

## Visual Metaphors
Flame vortex to knot closure.

## Data Flow from Engine Specs
Use QPE branch history and Dragon contraction steps as animation channels.
