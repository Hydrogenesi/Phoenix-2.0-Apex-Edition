# Engine Documentation Standards

## Required Section Structure

1. Overview
2. Architecture
3. Operators
4. Performance
5. Integration
6. Examples
7. Troubleshooting
8. Related Chapters

## Formatting and Notation

- Use Big-O complexity notation.
- Include benchmark context (hardware, dataset scale, runtime mode).
- Keep examples language-tagged and executable.
- Document config keys in tables.
- Include error classes and recovery action per failure mode.

## Integration Requirements

- Every engine page must link to Codex theory chapters.
- Every operator mention must map to codex chapters.
- Every example should indicate where it runs (Phoenix/QPE/Dragon).
