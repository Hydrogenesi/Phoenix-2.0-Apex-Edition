## Overview

This document is the single canonical reference for every operator in
The Triad. All 18 operators are listed together, organized by pillar,
so that their roles, domains, inputs, and outputs can be compared
side-by-side across the full system.

## I. Phoenix Operators — Transformation Layer

*Pillar: Phoenix 🔥 · Layer: Transform · Count: 8*

| **Symbol** | **Name** | **Domain** | **Purpose** | **Input** | **Output** |
|:----------:|----------|------------|-------------|-----------|------------|
| ⊕ | Genesis | Creation | Initializes new harmonic patterns from void | ∅ (void) | Ψ₀ — primordial pattern |
| ⊗ | Harmonic | Resonance | Amplifies and stabilizes an existing pattern | Ψ | Ψ′ — harmonized pattern |
| ⊛ | Recursive | Self-Reference | Folds a pattern back upon itself to deepen structure | Ψ | Ψ′ — recursively deepened pattern |
| △ | Apex | Culmination | Drives a pattern to maximum coherence and complexity | Ψ | Ψ_apex — apex pattern |
| ⊝ | Void | Dissolution | Returns a pattern to primordial void state | Ψ | ∅ (void) |
| ⊞ | Mirror | Reflection | Creates a symmetric inversion of a pattern | Ψ | Ψ* — mirror pattern |
| ⊳ | Convergence | Integration | Combines two or more patterns into a unified whole | (Ψ₁, Ψ₂) | Ψ_merged — unified pattern |
| ⊲ | Divergence | Separation | Splits a unified pattern into its component parts | Ψ | (Ψ₁, Ψ₂) — separated components |

### Phoenix Integration Flow

```
∅ ─[⊕]→ Ψ₀ ─[⊗]→ Ψ₁ ─[⊛]→ Ψ₂ ─[⊞]→ Ψ₂*
                               ╲       ╱
                                ╲     ╱
                                 [⊳]
                                  ↓
                                 Ψ₃ ─[△]→ Ψ_apex
```

### Hydrogenesi Recursion Laws

```
L(∅) = {∅}                         [Void lineage]

I(⊕(∅)) = I₀                       [Identity set at Genesis]
I(Op(Ψ)) = I(Ψ)                    [Identity unchanged under any Op]

C(Ψ, Ψ) = identity                 [Self-connection]
C(Ψ₁, Ψ₃) = C(Ψ₁,Ψ₂) ∘ C(Ψ₂,Ψ₃)  [Composition rule]

P(⊕(∅)) = {foundational properties}
P(Op(Ψ)) ⊇ P(Ψ)                    [Invariant set never shrinks]

G(∅) = {⊕(∅)}                      [Only Genesis from void]
G(Ψ) = {Op₁(Ψ), Op₂(Ψ), …}       [All valid operators projected]
```
