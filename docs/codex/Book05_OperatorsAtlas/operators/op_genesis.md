# Operator Hub: Genesis `⊕`

- **Formal definition**: `Genesis` maps state according to its governing pillar invariants.
- **Type signature**: `⊕: State -> State` (or tuple form for merge/split operators).
- **Axioms**: conservation of essential structure, bounded recursion, and apex-compatibility.
- **Codex examples**: `Book01_Genesis_Origin` and linked ceremony walkthroughs.

## 2) Engine Implementation

- **Pattern**: deterministic operator execution with explicit validation checkpoint.
