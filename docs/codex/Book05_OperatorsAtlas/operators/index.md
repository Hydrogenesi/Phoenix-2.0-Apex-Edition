## Operator Families
- **Phoenix family**: ignition, modulation, recursion, apex transition.
- **Hydrogenesi family**: identity, lineage, continuity, invariant control.
- **Knot family**: multi-pillar binding, closure, stability.

## Composition Patterns
- **Ignite → Preserve → Bind**: `⊕ -> I -> B`
- **Explore → Select → Converge**: `⊲ -> G -> ⊳ -> △`
- **Distributed Seal**: `⊗ -> P -> Ck -> T -> S`
