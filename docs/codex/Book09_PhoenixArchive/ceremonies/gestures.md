# Three-Finger Waltz Gestures

## Notation
- `P` = pulse
- `B` = bind
- `R` = release

## Core Sequence
`P -> B -> R` repeated per operator with one harmonic beat per gesture.

| Ceremony | Gesture Pattern |
|---|---|
| Ignition | P-B-R |
| Binding | B-P-B-R |
| Convergence | P-P-B-R |
| Apex Lock | B-B-R |
