    • Hydrogenesi: hy-dro-JEN-uh-see

    Preferred vs Legacy Terminology¶

    Preferred Legacy / Avoid Notes
    Quantum Pattern Engine (QPE) Quantum module Use full name on first mention.
    Dragon Node DragonNode Use spaced form.
    Three-Pillar System Triple stack Canonical architecture label.
    Operators Atlas Operator list Book title form is preferred.
    Codex docs corpus Use Codex for publication naming.
